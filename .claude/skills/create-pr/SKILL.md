以下の規約に従って Pull Request を作成してください。
ベースブランチの指定がある場合: `$ARGUMENTS`（デフォルト: `main`）

## 手順

1. 現在の状態を確認する（並列実行）:
   - `git status` で未コミットの変更を確認
   - `git log --oneline <ベースブランチ>..HEAD` で PR に含まれる全コミットを確認
   - `git diff <ベースブランチ>...HEAD` で差分の全体像を把握
   - リモートとの同期状態を確認
2. 未コミットの変更がある場合はユーザーに確認する
3. 必要であればリモートにプッシュする（`git push -u origin <ブランチ名>`）
4. PR を作成する

## PR の規約

- タイトル・本文は**日本語**で記述する
- タイトルは70文字以内で簡潔に
- Claude が作成した PR であることを本文に明示する
- `gh pr create` を使用し、本文は `--body` でインライン指定する（長文の場合は `--body-file`）

## PR 本文のテンプレート

```
## 概要
<!-- 変更の目的と内容を1〜3行で -->

## 変更内容
<!-- 主な変更点を箇条書きで -->

## テスト
<!-- テスト方法・確認事項 -->

---
🤖 Generated with [Claude Code](https://claude.ai/code)
```

## 注意事項

- PR に含まれる**すべてのコミット**を分析してタイトルと本文を作成する（最新コミットだけを見ない）
- ブランチ命名が `feature/<説明>` の形式に従っているか確認する
- `main` ブランチから直接 PR を作成しようとしている場合は警告する
