# 要件定義

## アプリのスコープ

このアプリは「支出を手軽に記録・把握する」ことに特化したツールです。
家計管理の習慣づくりを目的とし、シンプルさを最優先とします。

---

## 機能要件

### ユーザー登録
- Google認証を利用してユーザーを管理する

### 支出記録
- 登録、編集、削除ができる
- 支出の内容として、以下を記録できる
  - 必須
    - 日付
    - 金額
  - 任意
    - カテゴリ（食費、交通費、娯楽などプリセットから選ぶ）
    - need / wantが設定できる
    - 内容
    - メモ

### 支出一覧
- 記録した支出を確認できる
- 表示単位を設定できる（月 / 年 / すべて）
- 月・年の場合は前後に簡単に切り替えられる
- キーワード（内容、メモを検索）・カテゴリ・need/wantでフィルタリングできる

### 支出分析
- 記録した支出を分析できる
- 分析単位を設定できる（月 / 年 / すべて）
- 分析内容（MVP対象）
    - カテゴリ別の支出割合
    - need / want比率

---

## 将来の機能

- 寄付機能（外部サービス利用: Ko-fi）
- 多言語対応（英語以外の言語追加）
- PWA対応
- タグ機能
- 分類の作成・設定機能
- エクスポート機能（CSV出力、Excelへの貼り付け対応コピー）
- 分析の拡充（月次推移など）
- 連続登録（「Save & Add Another」ボタン）
  - 登録モーダルに「Save」とは別に「Save & Add Another」ボタンを追加する
  - 押下すると保存後もモーダルを閉じず、フォームをリセットして次の入力を受け付ける
  - 日付のみ前回入力値を引き継ぎ、金額・カテゴリ・need/want・内容・メモはデフォルト値に戻す
  - レシートをまとめて入力するなど、同日に複数件登録するシーンを想定

---

## 不採用とした機能

- 固定費・変動費の設定
  - タグで代用可能
- 固定費のサイクル指定
  - 支出を把握するだけのツールとしては過剰な機能
- 通貨変更時のレート換算
  - 為替APIへの依存・レート管理の複雑さに対して、このアプリのスコープでは過剰
  - 将来のエクスポート/インポート機能で、ユーザーが各自対応できる

---

## 非機能要件

- 対象ユーザー: 個人利用（シングルテナント）
- 対応環境: ブラウザ（PC、スマホ、タブレット）、ネイティブは将来対応予定
- レスポンスタイム: 通常操作で2秒以内を目安とする
- UI言語: 英語のみ。テキストを不要にできる箇所は絵文字を活用し、直感的に操作できるようにする
- 通貨:
  - ユーザーが使用通貨を選択できる
  - 通貨の変更は表示記号・フォーマットの切り替えであり、既存データの換算は行わない
  - 通貨ごとの小数桁数は ISO 4217 に準拠する（例: JPY → 0桁、USD → 2桁）
  - 金額は DECIMAL 型で保存する（詳細はデータベーススキーマ設計で定義）
